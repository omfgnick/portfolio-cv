# Fontes embutidas

Todas são self-hosted (o CSP do site é `font-src 'self'`) e todas são livres.

| Família | Arquivos | Licença |
|---|---|---|
| Fraunces | f00–f05 | SIL Open Font License 1.1 |
| Inter | f06–f12 | SIL Open Font License 1.1 |
| JetBrains Mono | f13–f18 | SIL Open Font License 1.1 |
| Rajdhani | f19–f24 | SIL Open Font License 1.1 |

A Rajdhani é a fonte da interface do próprio Cyberpunk 2077, e a OFL permite
embutir e redistribuir.

O wordmark do Cyberpunk 2077 e o letreiro do bar Afterlife são lettering
customizado e proprietário da CD Projekt Red. **Não estão aqui e não foram
reproduzidos.** O que o site imita é o efeito de tubo de neon — brilho,
oscilação e aberração cromática — feito em CSS sobre uma fonte livre.
